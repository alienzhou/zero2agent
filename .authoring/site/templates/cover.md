# 课程封面

封面会单独出现在分享图、缩略图和课程列表里。读者第一眼要知道这是「从零到一做 Agent」系列，其次才是本课增加了什么能力。

## 固定层级

1. 顶栏：Zero2Agent、阶段名和 Story 编号，例如 E03-S004。
2. 最大标题：**从零到一做 Agent**。在 1080px 画布上使用 80px 字号；Agent 使用系列强调色。不要缩成角落标识。
3. 系列说明：**亲手实现 Coding Agent · 开源实战课程**，明确是开发实践。
4. 本课标题：例如「会话落盘与恢复」，使用约 49px 字号。
5. 一句具体收益：例如「关掉程序，下次还能接着聊」，使用约 29px 字号。
6. 本课图解：表现本课真实机制或使用场景，标明教学示意；底部保留简短系列标签。

系列标题的位置、字号和强调色保持一致；本课标题、收益与图解随课程变化。正文页仍以本页知识点为主，无需重复封面大标题。

## 编辑入口

- E03-S001：直接维护 `site/chapters/epic03-story001/01-cover.html`。
- E03-S002、S003、S004：修改 `.authoring/site/chapters/epic03-storyXXX/author.cjs` 的封面分支。
- `.series-cover` 样式保存在各章 `course.css`，只作用于封面；不改变正文页布局。
- 保留小节原来的具体标题作为目录与检索入口，不把每章目录首项都改成同一个系列名。

## 交付检查

- 构建并保存生成源、HTML 与课程检索文字。
- 单独查看四张封面，确认系列主标题比本课主题更醒目。
- 在 PC 阅读器、390px 手机阅读器中检查；缩小后仍能读出「从零到一做 Agent」。
- 检查标题、课号、图解、脚注没有裁切、重叠或越出画布；检查文字内容、放大和导航。
- 原有验收记录只描述当时版本；修改封面后补充新的视觉检查记录，不覆盖历史证据。
