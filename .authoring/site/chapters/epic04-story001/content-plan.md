# E04-S001 内容计划 · v2

18 页（1 封面 + 17 内容）。用户反馈“课程页内容太单调”，初稿的三块矩形规则清单改为一次故障贯穿的讲解。版式由知识关系决定，保留系列封面、米白与红色强调；不靠新增装饰填页面。

| 页 | 读者要回答的问题 | 图形与教学方法 |
| --- | --- | --- |
| 01 | 这课解决什么实际问题？ | 运行现场 + 文件效果，系列封面 |
| 02 | 500 发生在写入之前还是之后？ | 4 次 HTTP 与 1 次写入的双轨时间线 |
| 03 | 为什么不能从头重做？ | 错误策略与传输恢复分叉对比，三种边界 |
| 04 | 怎样决定是否重试？ | 状态 / 动作 / 理由的决策表 |
| 05 | 为什么只能有一层重试？ | 3 × 3 点阵与 SDK 选项，乘法解释 |
| 06 | 怎样串起同一请求的不同尝试？ | 日志行拆解与关联括号，用量证据缺失 |
| 07 | 服务让等 30s，但只剩 10s 怎么办？ | 退避时间线与服务等待 / 剩余预算的条形比较 |
| 08 | 连上服务器为什么还会超时？ | 嵌套时限，连接 / 响应头 / SSE 的覆盖范围 |
| 09 | 等待时怎样接管？ | 实际生产 TUI 的本地故障画面 + 取消路径 |
| 10 | 完整参数片段可以执行吗？ | SSE 片段，完成 / 中断的提交分支与实际代码 |
| 11 | 工具参数错误由谁修？ | 模型与工具的交替对话，原调用 ID 配对 |
| 12 | 拒绝能被反复请求覆盖吗？ | 明确拒绝与两种后续操作，权限不升级 |
| 13 | 运行消耗究竟数什么？ | 四项默认额度的数字仪表，区别上限与用量 |
| 14 | 额度只有 1，模型给出 3 个调用怎么办？ | 批次回执单，三个调用必须三条结果 |
| 15 | stdout 没有 Error: 算成功吗？ | 真实命令、原生元信息与文件效果对照 |
| 16 | 时间到达时为什么不能立刻开始新 run？ | 预算 / 实际晚到写入 / 输入占用的时间线 |
| 17 | 配置与日志怎样互相验证？ | flag 与日志控制台，参数执行前检查 |
| 18 | 怎样亲手证明行为？ | 先预测再运行的三项实验与对照答案 |

输入修正 probe 是测试工具。点阵乘法不是旧版测量；示意时间线不按毫秒比例。教学分镜、日志 UUID 缩写、实际 PTY 派生截图、远端真实模型验证分别标明，避免把示意图当实测数据。
