# E03-S002 图解重制简报

2026-10-06。用户反馈原图文内容简陋，尤其是图。目标是让图承担教学：读者能沿箭头理解执行入口、三态分支、一次审批、路径重查和结果配对；保留本课完整的 16 页范围。

受众是有编程基础的 Agent Harness 学习者。代码事实固定于 73ecdbc，竞品比较采用原 2026-10-05 调研快照。最大 16 张含封面，1080×1440，未对外发布。

自由设计，沿用米白纸张、墨色文字、衬线标题、双边框封面的系列辨识。图中用绿色/勾号表示允许、赭色/问号表示等待、红色/叉号表示拒绝；颜色同时有文字与符号说明。使用可编辑 SVG 工程示意，精确表达关系，不需要装饰性插画。

同一案例为修改项目文件后运行验证。核心图形包含责任边界图、三态分支图、模式矩阵、规则决策链、精确匹配对照、审批界面标注、请求时序、超时竞态、路径前后对照、消息配对与终端交接。每页一个主视觉，图中说明通常 32px 以上；技术字符串和辅助标签 27–30px。封面和路径重查页先制作审查，再扩展全套。

验收需直接看全部 1080 图、手机缩放图和封面缩略图，核对箭头含义、ID 关联、边界与文本。自动 QA 仅辅助，不凭无溢出认定设计完成。HTML/CSS/author.cjs、图内全文、预览、来源、发布文案、图片 ZIP 与可编辑 ZIP 同步交付。
