# E05-S003 的 11 页学习路径

目标：读者能把本地 issue 服务接进 Harness，并解释启动、调用、回读及未知效果四个边界。18 页是上限；本稿用封面加 10 个必要步骤，不另补满额页面。

| 页 | 新增价值 | 主要形式 |
| --- | --- | --- |
| 1 | 将 MCP 接入现有 Harness 的总体关系 | 分支架构 |
| 2 | 与项目规则、Skills、下一课 Hooks 的职责关系 | 对照表 |
| 3 | 一次 stdio 生命周期 | 双泳道时序 |
| 4 | 启动信任与调用授权独立 | 两个门 |
| 5 | 同名工具隔离与本轮表固定 | 双服务路由 |
| 6 | 输入校验、正常/失败/不完整结果 | 校验流与三种结果 |
| 7 | 长结果来源与当前回读许可 | 结果流 |
| 8 | 效果后断线、配对与显式继续 | 故障时间线 |
| 9 | 连接与容量边界 | 生命周期与限额 |
| 10 | 实际 CLI/SDK 及离线入口 | 命令面板 |
| 11 | 正常、拒绝、未知三类验收 | 效果清单 |

合并了独立的“标准介绍”“范围声明”和“复盘总结”页；参数全集、JSON 配置、Schema 子集、故障矩阵、完整模型观察与证据表下沉到跟练、Spec 和研究材料。每页保持原字号、留白与 1080×1440 画布；生成源、pages.json、实际 HTML 均为 11 页。
