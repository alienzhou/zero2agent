# E03-S003 图解简报

2026-10-07。受众是有编程基础、正在实现 Agent Harness 的学习者。上一课已把权限接进执行入口，本课进一步让运行过程可见、输入可编辑、审批可回答、取消可验证。用户明确要求明显改善旧 CLI 的实际使用体验，而不只是增加状态日志。

18 页含封面，1080×1440；全部图形为可选文字的内嵌 SVG。沿用米白纸张、深色正文、衬线大标题与红色强调，绿色表示继续/完成，赭色表示等待，所有颜色同时配文字。主图通常 30–40px，少量技术字符串 27–29px；每页一个主问题。

图解顺序由使用疑惑进入界面构成和竞品启发，再讲事件与控制、身份、状态、审批焦点、取消收尾、输入体验和人工 PTY，最后接可重复的本地跟练。本课既教功能，也教“用事实建状态、用生命周期定义取消”的方法。

竞品对照使用 2026-10-07 固定源码与官方文档。真实 PTY 观察只覆盖 Codex 0.160.1、OpenCode 1.18.35 的输入/菜单/尺寸变化；不伪造审批和工具实机效果。所有课程内终端视图为当前实现的教学重排，未冒充产品原始截图。
