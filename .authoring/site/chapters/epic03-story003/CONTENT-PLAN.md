# E03-S003 内容计划

18 页，围绕一次“修改文件并验证”的任务。流程用方向与分支、状态用时间和身份、输入用所有权与前后对照表达，不把 Spec 段落搬进文字框。

| 页 | 读者的问题 | 主视觉 | 依据 |
|---|---|---|---|
| 01 | Agent 运行时能看见和控制什么？ | 有状态、不同工具结果和草稿的终端 | C01,C04 |
| 02 | 十秒没有文字意味着什么？ | 同一沉默分成三种等待与对应操作 | C01,C04 |
| 03 | TUI 如何组织正在发生的事？ | 状态、对话、工具、输入四区标注 | C01,C04 |
| 04 | 成熟产品有什么可借鉴？ | 事件关联、状态聚合、焦点移交、输入队列四种关系图 | R01–R05 |
| 05 | 通知和控制为什么分开？ | Core 与 TUI 两方向通道 | C02,C03 |
| 06 | 两个同名工具怎样不串结果？ | turnId + callId 关联与 seq 时间线 | C02,C04 |
| 07 | 工具完成为何仍在请求模型？ | 可回到模型的状态循环与终态出口 | C02,C03 |
| 08 | 工具什么时候才算开始？ | pending/approval/running 与拒绝、错误分支 | C02,C03 |
| 09 | 审批前必须看到什么？ | 完整参数与请求身份的终端面板 | C03,C04,C07 |
| 10 | 键盘输入现在属于谁？ | 普通输入、审批、人工 PTY 的独占所有者 | C04,C05,R02,R04 |
| 11 | 按取消后为什么还要等？ | 多种在途资源在 cancelling 区域收尾 | C02,C03,C06 |
| 12 | 取消后留下哪些结果？ | 已执行与未执行调用的配对回执及磁盘效果 | C02,C03,C06 |
| 13 | 运行中写的内容会丢吗？ | 取消前后同一草稿保留 | C04,C07,R05 |
| 14 | 粘贴与发送为什么分开？ | 多行内容整体进入缓冲区，Enter 才提交 | C04,R05 |
| 15 | 小屏幕如何看长工具结果？ | 摘要展开、保留内容滚动与100/44列对照 | C04,C08,R05 |
| 16 | 人工操作终端会泄露给模型吗？ | TUI暂停、PTY独占、仅状态返回 | C05,C07 |
| 17 | 如何亲手复现？ | 启动命令与重复/慢速/终端三步实验 | C07 |
| 18 | 本课边界与下一步是什么？ | 事件、显示、控制闭环；承接会话落盘 | C01,C06 |

工具卡和终端字段为教学重排。工具与整轮状态不能混用；取消已执行动作不回滚；忙时草稿不等于自动队列；width 示意不代表跨平台像素实测；下一课明确为待实现。
