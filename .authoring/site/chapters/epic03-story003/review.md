## 重复运行

先执行 `pnpm site:build`；可选启动 `pnpm site:preview --port 8793`。使用已有 Playwright 安装运行：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
CHROME_PATH=/absolute/path/to/chrome \
SITE_BASE_URL=http://127.0.0.1:8793 \
node .authoring/site/chapters/epic03-story003/verify.mjs
```

也可以从可解析 `playwright` 的环境运行并省略前两个变量。`SITE_BASE_URL` 省略时只检查逐页图解。`COURSE_QA_OUTPUT` 可指定截图和报告目录，默认是系统临时目录；不把本机依赖路径写进脚本，不要求把截图发布包加入站点。
