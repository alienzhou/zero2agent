# 推荐标题

Agent 没输出了，它是在工作，还是在等你？

# 正文

终端安静十秒，可能是在请求模型、等待命令，也可能是在等你批准。一个好用的 Agent，需要把这些状态解释清楚，还要让人能够介入。

Zero2Agent E03-S003，用 18 张图解拆开运行事件、工具身份、审批焦点、取消收尾和 TUI 输入。跟着本地演示，先拒绝一次、批准一次，再取消一次等待，观察真实文件和草稿发生什么变化。

课程还比较 Claude Code、Codex、Gemini CLI 与 OpenCode 的交互原则，并记录两款产品的隔离 PTY 输入观察。课程免费开源。
