## 正文

上一课，我们给 Agent 做了 7 个工具：能读、能搜、能写、能改。还缺一件事——改完代码，不能自己跑 `npm test`，不知道测试有没有过。

因为结果不在文件里，在命令的退出码和打出来的字里。所以这一课的 terminal，不是第 8 个文件工具，是 Agent 第一次让外面的程序自己跑。

外面的程序事先不知道会跑多久、会打出多少字、会不会一直不停。写「起进程」的代码不多；难的是：打出来的字，哪些要给 Agent 看。这一课分五个问题讲：

📌 **回执**：工具只能返回一段字。退出码、状态、输出都要写进去。五种情况：正常结束、输出太长、你取消、转后台、读输出卡住。

📌 **长输出**：太长就不放进对话，超过你设的行数或大小上限就存文件，只给路径，让模型用读文件工具自己看。

📌 **长命令**：没有 timeout 自动杀。跑久了可以转后台继续跑，也可以取消。

📌 **环境**：PATH 等要和你的 shell 一样；会卡住界面的交互要关掉。

📌 **后台进程**：转后台的要记下来；Agent 退出时问要不要停，默认不停。

代码开源，可以跟着从零写。评论区见 👇
