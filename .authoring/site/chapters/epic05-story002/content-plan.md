# 按需取到一套可用的修复步骤

读者学完应能组织一个标准技能，区分目录摘要、激活正文和按需资源，选择或停用技能，并从实际请求、文件和进程验证加载与权限边界。按必要的学习任务安排 **11 页（含封面）**，页数是本次取舍的结果，不作为固定模板。

| 页 | 新增的学习任务 | 采用的图形与内容取舍 |
| --- | --- | --- |
| 1 封面 | 识别系列与本课要实现的行为 | 逐层展开的文件图；不另加目录页 |
| 2 三层披露 | 判断什么进入初始请求，什么等到选中才读取 | 横向分层截面；动机与机制同页，不另讲抽象成本 |
| 3 技能目录与格式 | 写出目录名匹配、元数据合法的 SKILL.md | 目录树与真实 YAML 示例；完整字段规则下沉研究/Spec |
| 4 明确选择与模型选择 | 看懂两条激活入口如何汇合到宿主 | 汇合图与下一请求；当前正文、历史分离合入说明 |
| 5 先加载再执行 | 理解为什么混合业务批次必须先返回未执行 | 纵向时序；配对结果与有界重规划在同一因果链 |
| 6 资源相对根与读取权限 | 判断根内引用、路径穿越和越界链接 | 路径树/边界图；分页、哈希和预算合入说明，不列容量表 |
| 7 脚本与工具授权 | 区分读取脚本文本和真正启动进程 | 两条独立通道；allowed-tools 与只读拒绝合入 |
| 8 当前版本、恢复与停用 | 理解旧历史不能恢复当前激活或旧授权 | 两条版本/历史时间线；完整快照协议下沉 Spec |
| 9 终端控制 | 学会查看、选择、刷新、卸载和全局开关 | CLI 与交互终端入口；不假造执行回执 |
| 10 固定跟练 | 真正运行离线金额修复及拒绝案例 | 命令与产物流；不把模型服务当作默认前提 |
| 11 证据核对 | 分别证明正常任务按需、拒绝任务无效果 | 两条证据链；不放成功率或历史成绩表 |

数量/字节/时限表、完整错误矩阵、私有扩展格式与真实模型配置下沉到 Spec、跟练和验收资料。保留文件剖面、目录树、选择汇合、执行时序、路径边界、授权通道与历史时间线等不同构图；没有把它们改成连续的通用文字卡片。

画布固定为 1080×1440；保持系列 80px 主标题及内容页 66px 标题。正文图内主要字号为 28–36px，留足图形与说明空白。生成器只约束有效课程和 18 页上限；删除页面时同步清理旧目录产物。CSS 从本目录 style.css 生成，HTML/CSS/pages.json 与 author.cjs 同时提交。
