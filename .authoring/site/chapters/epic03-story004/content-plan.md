# E03-S004 内容与呈现计划

课程目标：读者先体验跨进程续聊，再能解释哪些数据应该保存、何时保存、如何验证恢复，以及崩溃与副作用的边界。

| 页 | 问题 | 呈现形式 |
|---|---|---|
| 1–2 | 为什么重启后忘记了 | 双终端封面、进程/文件寿命双轨时间线 |
| 3–5 | 保存什么 | 账本/摘要/时钟图标、源码对照、快照数据流 |
| 6 | 文件放哪 | 目录剖面与权限标签 |
| 7–9 | 何时、如何发布 | 操作时间轴、三阶段工序图、双进程竞争泳道 |
| 10–11 | 崩溃与断裂配对 | 事故现场图、配对与摘要切点图 |
| 12–13 | 如何重建上下文 | 原始消息分段图、校验闸门流程 |
| 14–15 | 如何操作 | 选择器界面标注、命令映射表 |
| 16–17 | 如何应对失败与兼容 | 成功/失败分支图、交互轨道对照 |
| 18 | 如何验证 | 可运行命令与三步实验 |
| 19–20 | 成本和后续 | 定性存储增长图、保存恢复续聊闭环 |

20 页共享字体、留白和配色，图形结构随问题改变。图中文字可选择，窄屏保留放大和正文模式。图示明确区分产品事实、教学重排、定性说明及实测证据，不把离线夹具说成真实模型。
