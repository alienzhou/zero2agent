# 封面系列识别

S003、S004 的大标题只说明本课功能，顶部仅有 Zero2Agent；S001、S002 的系列主题是小字。放到课程网站之外，读者无法迅速判断这是从零构建 Coding Agent 的系列。

统一最近四课：最大标题「从零到一做 Agent」，下接「亲手实现 Coding Agent · 开源实战课程」；Story 编号、本课主题、学习收益和机制图分别占固定层级。用 `.series-cover` 限定样式，正文页不受影响。

长期规则放在 `.authoring/site/templates/cover.md`，AGENTS.md 只保留入口与原则。保持旧课程版本 Tag 不变，封面修正另做 checkpoint。
