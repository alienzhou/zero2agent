# 本轮协作经验

1. “交互”不能默认解读为模型决策。先确定谁输入、谁看画面，再决定是否需要跨轮会话协议。
2. 参考成熟实现时复制职责分工，而不是把默认确认值、正文捕获和后台机制整体搬入。
3. 人工终端的完成条件包括归还输入权、恢复设备与清理后代；显示结果不等于已经完成生命周期。
4. 隐私测试应覆盖收尾窗口。只在子程序运行时关闭 Agent 输入，仍会把晚到按键写进历史。
5. 真实终端断连必须真的关闭外层 PTY；模拟信号或事件不能证明消失设备上的 I/O 行为。
6. 自动测试、工具驱动演示、用户人工验收是三类证据，不能互相冒充。
7. 先核对锁文件差异、限定提交范围；已有用户改动与全仓历史格式问题不顺手处理。
