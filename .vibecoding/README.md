```

├── README.md           # 本文件
├── E01/                # Epic 1: 基础 POC
│   ├── S001/           # Story 001: ReACT 基础版
│   │   ├── README.md

│   │   └── ...
│   ├── S002/           # Story 002: ...
│   └── ...
├── E02/                # Epic 2: ...
└── ...
```

**编号规则：**
- `E01` = Epic 01（阶段编号，2 位）
- `S001` = Story 001（迭代编号，3 位，每个 Epic 内从 001 开始）

## 脱敏规则

对话沉淀为文档时，**必须**对以下敏感内容进行脱敏处理：

| 类别 | 说明 | 脱敏方式 |
|------|------|----------|
| **密钥/令牌** | API Key、Token、Secret、密码等 | 替换为 `<REDACTED>` 或 `sk-***` |
| **个人信息** | 真实姓名、邮箱、手机号等 | 替换为占位符，如 `<USER>` |
| **目录路径** | 包含用户名的绝对路径（如 `/Users/xxx/...`、`/home/xxx/...`） | 替换用户名部分为 `~`，如 `~/program/works/zero2agent` |
| **环境信息** | 主机名、IP 地址、MAC 地址、OS 版本等系统信息 | 移除或替换为通用描述，如 `<HOST>` |
| **环境变量** | `.env` 文件内容、`export` 的敏感变量值 | 只保留变量名，值替换为 `<REDACTED>` |
| **内部 URL** | 非公开的内网地址、私有仓库地址、内部 API 端点 | 替换域名为 `<INTERNAL_URL>` |
| **数据库连接** | 连接字符串、DSN 中的用户名密码和主机信息 | 替换为 `<DB_CONNECTION>` |
| **第三方账户** | GitHub 以外的私有服务账户、组织内部 ID 等 | 替换为 `<ACCOUNT>` |

**原则：**

1. **保留技术价值**：脱敏不应影响对话的技术可读性，保留足够上下文让读者理解决策过程
2. **项目信息可保留**：项目名（`zero2agent`）、公开仓库地址、包名等公开信息无需脱敏
3. **宁多勿少**：拿不准是否敏感时，先脱敏
