# 实施记录

- 开放格式定义文件与优先语义；搜索边界、权限、预算、缓存和 UI 由 Harness 明确定义。项目原文放在用户级覆盖层，不能变成系统权限或工具授权。
- 嵌套规则是首次写入之前的约束。整批先预检，新作用域使整批未执行并配对返回；只在实际 execute 前重验才能覆盖审批期间变化。
- 重新规划应比较当前适用规则。移出无关目录并不等于新约束，错误地计数会消耗有限预算；实际删除仍需要模型知晓。
- 搜索失败必须检查工具实际目录。find_files 的宿主 cwd 与 Agent cwd 混用会让正确的 glob 返回空，不能以增大模型预算掩盖。
- 没有规则时保持旧请求开销，是兼容上下文压缩的可观察行为；恢复历史后则需要说明摘要中的旧规则不再权威。
- 最近读取和上次发送是两个状态。刷新不调用模型，UI 应显示两者，原文不写入诊断日志。
- 失败证据与版本应保留在独立归档。Git 只保存可复现脚本、少量汇总与哈希；固定任务和预算不因失败而悄悄调整。
- 18 页课程使用文件树、层级图、时序、批次图与真实跟练解释机制；机制图不能冒充真实运行证据，AI 检查也不能代替人工 review。
