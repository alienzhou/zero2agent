# E03-S005 运行日志与问题追查

## Current Focus

实现可关联、可落盘、可读取的运行日志；验证请求、工具、审批、取消、压缩与宿主保存的完整链路。

## Confirmed

- 用户要求完整推进本课，沿用上一课工程、教材、验收与固定版本交付。
- 保留所有原有 TUI、plain、单次 CLI、管道、会话恢复和人工终端功能。
- 运行日志与会话快照、工作上下文分工；日志查看不能执行历史工具或改模型消息。
- Core 只发结构化事实；宿主负责本地 JSONL、错误可见性、读取与展示。
- 每个宿主 run 独占 UUID 文件；关联 sessionId / operationId / requestId / toolCallId。
- 元信息白名单，不保存 prompt、模型正文、工具参数/输出、原始异常信息、请求 headers、API key、PTY 私密字节。
- 保留原有系列封面层级，20 页图文课程有机制图、时序、文件结构、故障分支和跟练。

## Pending

- Core 请求和工具诊断事件；宿主有界写队列与 flush。
- CLI 与 TUI 日志浏览、只读检查、不完整尾行诊断。
- 离线、SDK/HTTP、真实 PTY、真实模型与浏览器验收。
- 文档、复盘、Tag、草稿 PR 与最终逐项审计。

## Rejected

- 将日志自动注入模型消息；日志读取时重放工具。
- 记录完整原始 payload 后再以正则猜测隐私。
- 将日志成功当成文件回滚、强事务或每次网络重试的证据。
