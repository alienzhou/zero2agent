# D01：事实事件与本地日志分层

运行事件服务当前屏幕，日志服务事后追查，快照服务下次续聊。Core 增加诊断观察者：操作起止、模型/摘要/计数请求起止、权限判定、工具状态和压缩阶段；不包含正文。观察者异常不得改变执行、审批或历史。

宿主为每次进程运行创建独占 UUID JSONL 文件，记录版本、runId、递增文件 seq、时间与各级身份。请求 ID 在 SDK 调用前创建并在完成/失败时沿用；SDK 内部重试属于一次逻辑请求，不假装能观察每个 HTTP 尝试。后台摘要保留启动它的 operation/session 身份，即便当前轮已经结束。

本地有界队列不在 text-delta 热路径逐字写盘。flush 在操作结算和退出边界执行；错误或队列/文件上限触发可见降级，Agent 继续工作。不静默宣称日志完整。每进程独占文件避免多进程覆盖。

读取只接受当前工作区 UUID，版本与 schema 校验后投影；完整行可读、末尾未完成行标记不完整，中部坏行明确失败。缺少 operation/request/tool 结算意味着证据未闭环，不能推断没有副作用。
