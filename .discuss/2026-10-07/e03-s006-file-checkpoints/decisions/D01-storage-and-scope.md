# D01：按受控写入存储，避免第二套 Git 仓库

全目录快照会把扫描成本与仓库规模绑定，忽略策略还可能带入依赖或秘密。只保存文本 patch 虽小，却依赖基础版本、补丁顺序和文本语义，难以覆盖删除和二进制。整文件 CAS 易懂，但大文件小改动仍保存整份新内容。本课采用内容定义分块 CAS：只读取当前工具涉及路径，独立压缩内容块，相同块复用；manifest 保存顺序、完整内容哈希、长度和权限。

粒度为一次受控工具调用，不冒充整个工作区时间点。write_file / replace_in_file / delete 声明可信文件路径元数据，Core 在权限允许后等待宿主控制接口，再执行真实工具。terminal 不靠解析命令猜路径。

回退按 before/after/live 三方比较：live 与 after 不符则冲突，全部预检通过后逐文件替换。多文件非原子，先持久化恢复意图，遇到中断可检查已到达目标的文件并继续；既不重放工具，也不抹除原史。pending 捕获不自动认定安全，需要展示当前状态并明确确认恢复。

候选默认预算：单文件 32 MiB、一次调用 64 MiB、最多 50 条已完成记录、30 天、工作区存储 256 MiB。按实际实现与基准修订；同时报告逻辑和文件系统分配字节。容量满不会悄悄跳过保护，显式关闭开关由用户选择。
