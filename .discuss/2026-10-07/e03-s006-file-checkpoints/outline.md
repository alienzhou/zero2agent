# E03-S006 文件 Checkpoint 与回退

用户要求完整推进课程，明确拒绝用 shallow/shadow Git 模拟 Checkpoint，要求综合空间、效率和效果。沿用已有 TUI、会话、权限、日志与人工终端契约。系列封面继续突出「从零到一做 Agent」。

本课选择对受控文件工具按调用记录涉及路径的前后状态；不复制仓库、不扫描无关文件、不修改用户 Git。内容定义分块、SHA-256 去重、deflate 压缩；有数量、字节和单文件上限。保存失败阻止尚未执行的受保护写入；已发生的效果不能伪装撤销。

交互：列表 → 改动预览 → 回退预览 → 明确确认 → 重新校验冲突 → 执行。回退自身也是可撤销记录。任意 shell、人工终端、外部系统副作用不在自动捕获范围；历史与日志不倒退。跨进程恢复仅处理已记录文件，并检测后续手工编辑。

阶段：研究与设计；存储及 Core 边界；TUI/CLI；故障、空间、性能与交互验收；教学/图解/跟练/固定 Tag/PR。人工审阅与部署单列，不冒充完成。
