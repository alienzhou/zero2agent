# 在线课程站点

用户希望把 content-generator/zero2agent-xhs 的 HTML 图文迁入 Zero2Agent，部署到已有 Nginx 服务，不部署导出的图片，并获得在线书籍式的导航和章节选择。

本地第一版沿用原图解，按课程、章节、小节组织。左侧切换章节，中间连续阅读，右侧定位小节；提供全文搜索、上一章与下一章、当前浏览器的进度记忆。窄屏通过抽屉目录、图解放大和文字内容阅读。

site/ 是完整的静态部署目录，HTML 与 CSS 直接提供给浏览器。复制正式编号的内容页与引用的样式，排除预览、备份、导出 PNG、ZIP 与制作工具。原素材保留在 content-generator 中。唯一的本机图片引用改为内嵌 ReAct SVG。

本轮只做本地实现与验证；服务器地址、域名和部署账号未提供，不执行远端发布。
