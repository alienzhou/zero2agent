# D04：按用户路径分块推进 P0 / P1

## Status

Confirmed

## Date

2026-03-20

## Decision

文档导航优化不采用“一次性全量补齐所有页面和所有链接”的方式推进，而采用“按用户路径分块推进”的方式实施。

每次优化都遵循同一个原则：

1. 先选定一条用户路径
2. 先补齐这条路径上的 P0 链接与入口
3. 再逐步增加这条路径上的 P1 增强项

## Why

虽然 P0、P1 和用户路径本身都重要，但如果同时从页面结构、入口文案、互链关系三个维度全面展开，改动会比较散，也不容易验证是否真的改善了阅读体验。

按用户路径推进有几个好处：

- 范围更清晰
- 更容易判断每一轮优化是否打通了一条真实阅读路径
- 可以先服务最重要的用户，再逐步扩展

## Consequences

正向影响：

- 每轮改动都有明确目标
- 更容易安排优先级
- 文档结构能逐步演进，而不是一次性重写

实施含义：

- 首次访问路径可以作为优先候选
- 回访用户路径可以单独作为下一块优化
- P1 项不需要一开始全部完成，只要围绕当前路径逐步补充即可

## Notes

这条决策意味着，后续不应只按页面维度列任务，还应按用户路径来组织实施计划。
