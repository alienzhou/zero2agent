# D02：替换语义 —— 精确匹配 + 唯一约束

## 状态
✅ Confirmed

## 决策

`old_string` 必须**逐字符精确匹配**（含缩进、空白、换行），并且（默认）在文件里**唯一出现**：

| 匹配结果 | 行为 |
|----------|------|
| 0 次 | 返回 `Error:`（未找到匹配内容） |
| 1 次 | 替换该处，返回成功回执 |
| ≥ 2 次 | 返回 `Error:`（匹配不唯一，要求补充上下文）——**不自动选第一个** |

## 竞品对照

OpenCode / pi-mono / Gemini 的 `edit` 都要求 `old_string` 唯一出现，多处则报错；Aider 的 SEARCH 块同样要求精确唯一（匹配失败会多轮重试）。

## 理由

1. **唯一性约束是「防止改错位置」的关键**：倒逼模型带上足够上下文（函数签名、注释、相邻行）来定位目标，从根上降低「改错地方」的概率。
2. **不自动选第一个**：静默选第一个看似省事，实则把「改错位置」的风险转嫁给模型无法察觉的地方。显式报错让模型自己补上下文，比猜测更可靠。
3. **精确匹配（含空白）是确定性契约**：模型必须复现原文的精确缩进；任何漂移都会得到明确报错，而非静默失败或错位替换。
