# D05：边界情况推迟到扩展阅读

## 状态
✅ Confirmed

## 决策

S002 的 MVP 实现**不处理边界情况**（截断、超时、输入校验等），这些内容放到 Spec 的"扩展阅读"章节。

### 扩展阅读 Deep Dive 话题池

- **边界情况处理**：截断策略（量的边界）、输入校验（质的边界）、超时机制（资源边界）
- **设计取舍**：参数多 vs 少、绝对路径 vs 相对路径、排序 vs 不排序
- **业界进阶方案**：Gemini CLI 自动上下文丰富、降级策略、模型适配 schema
- **后续可扩展参数**：`literal`/`case_sensitive`、结果排序、流式早停

## 理由

1. 当前版本是基础版，先保证核心功能可用
2. 边界情况作为学习者自主思考的题材，放在扩展阅读引导探索
3. 后续迭代可以逐步实现这些话题
