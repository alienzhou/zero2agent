# D08：context 参数设计

## 状态
✅ Confirmed

## 决策

`context` 作为第 5 个参数暴露给 LLM，默认值为 **0**（不带上下文），LLM 按需指定。

### 最终参数表（5 个）

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `pattern` | string | 是 | — | 搜索模式（正则表达式） |
| `path` | string | 否 | 项目根目录 | 搜索目录 |
| `include` | string | 否 | — | 文件过滤 glob |
| `exclude` | string | 否 | — | 文件排除 glob |
| `context` | number | 否 | 0 | 匹配行前后各显示的上下文行数 |

## 理由

- 默认 0：结果紧凑，搜索大量匹配时 token 少
- 暴露参数而非固定值：LLM 搜函数定义时需要上下文，搜 import 时不需要，应该有选择权
- 截断做简单版，复杂截断策略放入扩展阅读
