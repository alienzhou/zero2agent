# D10：排序策略、简单截断、工具描述

## 状态
✅ Confirmed

## 决策

### 排序策略
- 结果按**文件修改时间降序**排列
- 最近修改的文件排在前面，更可能是当前关注的上下文
- 实现方式：应用层 `stat()` 取 mtime 后排序（与 OpenCode 一致）

### 简单截断
- 匹配上限 **100 条**（四家竞品的共识值）
- 超出时在结果末尾提示截断，建议缩小搜索范围
- 复杂截断（单行长度限制、总量限制、分层提示等）放入扩展阅读

### 工具描述
- 使用 TypeScript **模板字符串**，将截断参数值嵌入 description
- 确保描述和实际行为自动同步（参考 Pi 的做法）
- 具体措辞在写 Spec 时定稿
