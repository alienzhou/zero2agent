## 目标与结论

文档明确区分文件编辑工具和 Bash 改动，回退菜单提供代码、会话或组合恢复选项。链接文件、外部编辑和子 Agent 的范围另有约束；不能把屏幕上的“回到上一轮”解释为所有系统副作用都被撤销。

本课借鉴的是显式恢复范围和先选择再确认的交互；实现粒度为单次受控工具调用，不宣称达到其整轮 rewind，也不推测其内部是否使用某种块存储算法。

保留策略与正文恢复是单独的数据治理问题。本课默认 50 条/30 天及 256 MiB 预算来自本项目设计，不是竞品性能结论。
