## 验证过程与修正

最初全部 live 启用时 25 项失败：旧 fixture 未给未知模型配置请求预算，也没有给非 TTY 写入和命令声明宿主授权。只修测试配置，保留生产 default 规则。非 TTY 任务的授权范围由 read/edit/terminal fixture 显式选择，本课的 default 审批另有独立真实 PTY 验收。

追加 20 项实际交互后，旧大输出回读被外部路径权限拒绝，另一个旧断言依赖模型是否复述 Wall time。让测试生成的日志留在临时工作区，并通过真实请求中的工具回执及磁盘内容核对输出完整性和耗时，不以模型措辞代替执行事实。

最后 D05 的最小父环境覆盖了采集代理地址，命令运行了，但采集器记录为空。修正记录器对路由和认证配置的持有后，D05 三项重新验证通过。路由过滤只影响这些显式 API 环境覆盖；其余 47 项已有相同生产代码和测试逻辑的有效记录。失败报告完整保留，未删除或改写。
