# 2026-10-07 两款 TUI 的隔离实机观察

这是通过真实进程和 PTY 输入得到的记录，不是竞品截图临摹，也不是项目自己的固定模型演示。环境为 macOS；使用 `@lydell/node-pty` 启动产品，用 `@xterm/headless` 解析 ANSI 并保存文字帧。**文字帧不等于像素截图**，没有验证所有终端渲染兼容性。

## 隔离与复现范围

每个产品使用新建临时工作目录与子进程 HOME/XDG，环境只传递 PATH、TERM、LANG 与本次显式配置；未继承真实 API key，未读取原账户会话。Codex 用 `--no-daemon` 避开共享服务，并设置自定义 provider 为 `http://127.0.0.1:9`。OpenCode 禁用 provider、自动更新、分享、外部 skills 和默认插件。未提交模型任务；Codex 只执行本地 `/status`，其界面显示 token usage 0。

Codex CLI 为应用自带 **0.160.1**。OpenCode 使用官方 `opencode-ai` npm 包，临时安装在 `/tmp/zero2agent-research/ux-opencode`，实际版本 **1.18.35**；未全局安装。该安装版本与固定源码 HEAD 不保证完全对应，报告分别引用，不把源码当作该二进制的精确构建证明。

[observer-used.mjs](./observer-used.mjs)是本次实际使用的捕获驱动，保留当时路径以追溯；不是面向用户的通用安装脚本。每个目录的 `metadata.json`记录启动参数、尺寸、动作和进程退出信息；`terminal.ansi.gz`保留原始输出；编号 txt 是逐次观察。复现需要修改驱动中的本机二进制/依赖路径，并重新创建隔离目录，不应指向个人配置。

## 已实际观察

| 项目 | Codex 0.160.1 | OpenCode 1.18.35 |
|---|---|---|
| 初始界面 | 任务说明、输入和底部模型/目录 | 首次 provider 弹层；Esc 后输入区和快捷键提示 |
| slash 菜单 | `/` 展示候选，`/stat` 筛选状态命令 | `/` 展示候选，`/he` 有帮助等匹配 |
| 多行粘贴 | 中文与两行英文作为未提交的三行草稿 | 三行显示 `[Pasted ~3 lines]`；两行直接可见 |
| 行编辑 | Ctrl+A 后插入 EDIT，改变当前第三行开头 | 本轮未单独验证所有编辑键 |
| 草稿保护 | Ctrl+R 搜索后 Esc 恢复三行草稿 | Ctrl+P 菜单后 Esc 恢复两行草稿 |
| 历史 | Up 回忆已执行的本地 /status | 本轮未建立真实会话历史 |
| resize | 100×32→44×18→100×32 后草稿保留 | 同尺寸变化后草稿保留，未证实窄屏像素无残影 |
| 退出 | 清空输入后 Ctrl+D，进程 exitCode 0 | 清空输入后 Ctrl+D，进程 exitCode 0 |

两次观察都正常退出，未留下待运行产品进程。最初将 Esc 与 Ctrl+C 连续写入同一批字节，在 OpenCode 中没有清掉 `/he`；单独发送 Ctrl+C 后正常清空。这表明按键时序必须如实记录，不能只凭目标动作宣称通过。

窄屏 OpenCode 的 headless 文字帧含旧缓冲区内容，恢复宽屏后正常。本报告据此只能确认草稿保留，不能断定是产品视觉 bug 或全终端兼容通过。后续需要真实终端像素取证再下结论。
