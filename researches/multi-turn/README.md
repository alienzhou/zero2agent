## 对本课的启发

1. Session 的寿命必须长于单次 Loop；历史包含完整 assistant 内容与工具回执，不只是聊天文字。
2. 同一会话并发提交、运行中清空都需要拒绝；本课不引入队列。
3. 回滚消息不等于回滚文件。保留已经完成的调用／结果对，网络失败后追加明确的宿主中断标记，不自动重跑工具。
4. 截断的工具调用不能执行；必须用失败回执补齐配对，不能把不完整参数当作可靠指令。

本课只借鉴以上契约，不引入上游的持久化、图结构、steering、自动重试或上下文压缩。设计见 [Story](../../specs/E03-product-foundations/S001-multi-turn/README.md)。
