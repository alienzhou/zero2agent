## 功能验收

### grep_search 基础功能

| 检查项 | 优先级 | 模块 |
|--------|--------|------|
| 能搜索到存在的 pattern | P0 | Tools |
| 返回结果包含文件路径、行号、匹配内容 | P0 | Tools |
| 结果按文件修改时间降序排列 | P0 | Tools |
| 超过 100 条匹配时截断并提示 | P0 | Tools |
| 工具正确注册到 allTools | P0 | Tools |
| Agent 循环能正确调用 grep_search | P0 | Loop |

### 参数功能

| 检查项 | 优先级 | 模块 |
|--------|--------|------|
| `pattern` 支持正则表达式 | P0 | Tools |
| `path` 缺省时搜索项目根目录 | P0 | Tools |
| `include` 能过滤文件类型（如 `*.ts`） | P1 | Tools |
| `exclude` 能排除文件（如 `*.test.ts`） | P1 | Tools |
| `context` 能返回匹配行前后的上下文 | P1 | Tools |
| `context` 默认为 0（不带上下文） | P1 | Tools |

### 输出格式

| 检查项 | 优先级 | 模块 |
|--------|--------|------|
| 首行包含匹配总数和文件数 | P1 | Tools |
| 文件块用 `---` 分隔 | P1 | Tools |
| 匹配行格式 `L行号: 内容` | P1 | Tools |
| 上下文行格式 `L行号- 内容` | P1 | Tools |
| 使用相对路径 | P1 | Tools |
| `.gitignore` 中的文件被自动排除 | P0 | Tools |

| 检查项 | 优先级 | 说明 |
|--------|--------|------|

## 已知限制

| 限制 | 说明 |
|------|------|
| 无复杂截断 | 只做匹配条数截断，无单行长度和总量限制 |
| 无超时机制 | 大仓库搜索可能较慢 |
| 无降级策略 | ripgrep 不可用时无 fallback |
| 无路径安全检查 | 可以搜索任意路径 |
| 无早停优化 | 达到上限后 ripgrep 仍会继续跑 |

---

## 优先级定义

- **P0** = 必须检查（核心功能，不通过则不可发布）
- **P1** = 应该检查（重要功能，影响用户体验）
- **P2** = 建议检查（边缘场景，可后续完善）
