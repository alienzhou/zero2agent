# 概述与文档导航

[课程](../README.md)

本课让压缩后的 Agent 能继续按有效事实工作：先量化哪里丢失，再保留来源和提供回查，最后验证实际任务效果。

沿用 E03 的原史/发送视图分离、E04-S001 的请求与运行预算、S002 的大工具结果引用。新增质量评测、宿主历史索引、同会话原文回查与来源权限目录；获批扩展再加入按回合显式产物契约、有界完成校验和未解决读取纠错。复杂的全局记忆、跨机器迁移和断点续跑仍在本课范围外。
