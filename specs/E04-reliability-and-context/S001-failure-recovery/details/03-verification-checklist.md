# 验收计划与当前状态

[课程](../README.md)

当前只有基线构建通过，新功能尚未验收。

| 层级 | 必须证明的行为 |
| --- | --- |
| 请求策略 | 408/429/5xx/网络/超时有限恢复；非重试错误停止；Retry-After、取消与额度正确 |
| 真实 SDK | 实际 HTTP 次数等于 attempt；半截流无正式历史或工具效果；重试后完整结果只提交一次 |
| 工具与预算 | 修正重新授权；相同失败停止；批次全配对；已完成效果不重放；不配合取消的工具等待结算 |
| 上下文 | provider 计数/摘要采用同一策略；溢出恢复和原史配对继续成立；后台身份保留 |
| 宿主 | 单次/管道/plain/TUI 配置与重试可见；Ctrl-C、焦点、保存及退出终端恢复 |
| 日志 | 逻辑请求和每次尝试关联；无正文、凭据或人工终端内容；旧日志可读 |
| 真实服务 | 单独记录模型任务效果与请求故障注入范围；文件效果不以模型文字代替 |
| 交付 | build、全量测试、E2E tsc、lint、改动格式、site build/check、18 页布局、PC/H5 交互、固定版本与审计 |
