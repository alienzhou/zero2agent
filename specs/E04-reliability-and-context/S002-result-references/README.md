[Epic 4](../README.md) | [首页](../../../README.md) | [迭代日志](../../../CHANGELOG.md)

测试输出有几十万字，真正回答问题的可能只有最后一段。E02-S003 已解决终端输出落盘；这一课让保留下来的结果可以按需、有限、可校验地取回。

实现阶段。验收与跟练随实现补全。

## 本课交付

统一大工具结果引用，复用终端输出流；每次回读限制字节量，返回后续游标；正文具有 SHA-256 与来源身份。会话保存引用元信息，正文保存在本机私有结果目录，重启后使用当前权限重新读取。过期、容量耗尽、文件清理、内容损坏有明确结果，不能诱导重放产生副作用的工具。
