# 技术设计

[课程](../README.md)

## 现有能力与问题

terminal 的 OutputSink 在 800 行或 20 KiB 后流式保存输出，回执给临时路径；慢命令也会保存，后台命令仍在写入。ContextManager 在压力达到水位时另存较大的工具正文，并生成长行 chunks 副本。read_file 虽有行范围，却先读取整个文件。工作区外临时路径默认 ask、read-only deny；现有压缩引用不在快照中。

## 契约

1. Session 持有 ResultStore。大于 20 KiB 的新工具正文先完整保存，再把来源、大小、SHA-256、失效时间和引用作为配对 tool_result。小输出沿用原行为。大结果正文不复制进会话 JSON；旧会话大正文保留原史，只在发送视图生成引用。
2. 新工具 read_tool_result 接受 opaque reference、offset、limit。UTF-8 字节偏移，默认/最大读取 4096 字节，返回 next_offset/eof 和 JSON 转义正文；支持任意长行，不额外写 chunks 文件。正文仍是不可信工具数据。校验流式进行，不把整个文件读入内存。
3. 来源记录 toolCallId/toolName 及读取边界。读取走当前 PermissionController，明确 deny/ask 仍有效；引用不是任意文件路径，也不授权执行原命令。跨工作区恢复不能拿到原工作区正文。
4. 终端 OutputSink 保留流式收集，在已结算结果上登记现有文件，避免重新保存回执或整份日志。后台仍在增长的文件明确处于未封存状态；不伪装成不可变结果。
5. 私有正文按内容哈希保存，默认单结果 16 MiB、每会话 64 MiB/128 引用、TTL 7 天。拒绝静默丢弃与重跑；容量或写入失败保留工具已执行事实。正文损坏、被清理、过期返回不同错误。过期内容可回收，活跃引用不被容量回收挤掉。写锁串行发布与回收，正文 mtime 保存最新租约，避免旧快照删除新引用正文。终端执行前预留单份最大容量，后台 spool 保留预留，关闭后计实际大小；短命令释放预留。目录别名先解析配置父路径已有祖先，私有子树拒绝 symlink。
6. 快照携带版本化的结果目录身份和元信息，校验后才能替换状态；不保存旧审批、进程或凭据。恢复后原引用在同机同工作区且未过期时可读，否则明确说明原因。重新启动不重放工具。
7. 回读属于普通工具调用，消耗 S001 工具额度；返回后的模型请求继续经过上下文预算。日志保持元信息白名单。

## 证据

单元测试覆盖权限、边界、UTF-8、哈希、生命周期与失败；真实本地 HTTP/SSE 验证模型请求大小与工具配对；新 Node 进程恢复并读取同一正文；真实模型验证从大输出中找到随机证据。课程把示意与实测分开。
