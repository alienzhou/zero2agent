## 仍然存在的边界

Hook、MCP 与终端里的受信任本地程序有宿主权限；没有 OS 沙箱。文件审计只覆盖当前自动允许读取的工作区内声明 watch、契约及受控写入路径；普通 shell 与未声明外部效果不由它证明为零。进程清理实测普通 POSIX 组，主动逃逸和 Windows 后代未验收。发生内核级文件系统阻塞时，Node 文件核对无法强制中断系统调用。

工程格式本次变更通过，全库 11 个既有文件的 Prettier 问题单列且字节与基线一致；不混入无关格式变更。AI 检查不代替人工 PR 审阅。

2026-10-18 的 PR #31 最终复核修正两处边界：完成前显式新检查继续审计原契约路径；beforeComplete 的无效 tool 筛选在入口拒绝。三条旧代码失败回归保留，修复后通过。最终源码 964d679 的固定离线/真实候选各 2/2，模型和 8/12/120s 门槛未变；d3b4aec 的成对作用域观察保留在原版本，不冒充此次源码对照。新证据独立补充归档。
