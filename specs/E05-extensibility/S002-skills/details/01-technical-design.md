# 先给摘要，选中后再加载

## 标准与本产品策略

固定标准源码 `agentskills/agentskills@69ef37e9424c0a7ea9dd2293b559e43ec8176379`，核对日期 2026-10-17；标准没有独立发布版本号。`SKILL.md` 使用 YAML frontmatter 和 Markdown 正文，必需 `name` 与 `description`。名称按 Unicode NFKC、字符数与小写字母/数字/连字符校验，并与所在目录匹配；描述非空、最多 1024 字符。支持可选 license、compatibility、metadata、allowed-tools 的标准类型。

以开放规范为基线，参考官方实现并采用本节严格策略；不自动修复 YAML，不接受重复键、alias、自定义 tag 或未知顶层控制字段。兼容性说明是文本，没有标准 dependencies 字段；缺少参考文件在实际请求读取时失败，不自动安装依赖。allowed-tools 为实验字段，显示“未实现权限语义”的警告，不批准操作。标准建议与本项目选择分别记录在 [调研](../../../../researches/skills/README.md)。

默认发现 `cwd/.agents/skills/<name>/SKILL.md`，仅扫描一层；额外目录由调用方显式配置，不搜索用户 home 或任意父目录。显式技能目录既可为集合根，也可为包含 SKILL.md 的单个技能根。来源身份绑定实际注册路径，重名不得静默覆盖，唯一名称或来源 ID 选择。目录名、大小写准确的 SKILL.md、扫描/容量/权限均按本节规则处理。

## 三层请求内容

目录只包含有界的名称、描述、来源与状态，不会把未选正文作为当前激活覆盖层注入请求，也不主动读取参考文件。激活工具返回小回执，下一请求用独立 user 级覆盖层加入当前正文；系统只追加固定的低于用户要求、不能扩权与旧历史失效说明。参考文件通过相对技能根的专用分页入口读取，返回真实来源、哈希、范围和正文。

激活与普通业务工具不能混在同一批次中执行：整批先返回明确未执行，让模型单独加载后看到正文再提交操作；有限重规划受每轮 3 次限制和原工具预算约束。已选技能在每个请求前重读；模型响应期间版本变化时，效果前重新规划；审批/批中变化则保留已完成结果，阻止剩余调用。加载绝不执行脚本，脚本只能作为普通 terminal 调用再次授权。

## 权限、来源和边界

发现头部、加载正文与读取资源均使用当前 read_file 权限。词法路径与物理路径分别检查，授权 cwd 保持原工作区；外部显式目录不是授权。技能资源必须为根内相对路径，拒绝绝对路径、路径穿越、物理越界和非普通文件。读取使用有界句柄、UTF-8 校验与已打开句柄与当前路径的文件身份、前后状态核对（含整父目录原子替换）；拒绝、超限、删除、损坏不得回退到旧正文或标为成功。

引用不会自动展开，脚本不会自动启动。metadata 是不解释的作者信息；其中的 version 不代替实际内容 SHA-256。普通 shell 仍有宿主进程权限，不把技能目录检查描述成 OS 沙箱。

## 会话与兼容

Agent 持有易失目录与正文，SessionSnapshot.skills 字段仅保存 version=1 的有限选择元信息（身份、源路径、旧内容版本），该字段不保存正文、搜索根、审批或进程；整个快照仍保留原有消息与工具结果。包含技能选择的磁盘会话使用 version=3；旧格式继续兼容，旧程序明确拒绝新格式。恢复先完整校验，随后按当前配置目录、权限与版本重建；失踪/被改动来源可见，历史中已有的技能文本只作为过去事实，不构成当前激活；加载覆盖层本身不自动存入历史。

全局关闭或单项卸载后，新请求不再注入当前正文；旧工具结果作为历史保留，不能重新激活技能。关闭扩展以及没有技能的普通会话保持原请求与工具表。当前覆盖层在预算计数、自动压缩与手动压缩中一致，查看与刷新不发模型请求。历史 read_history/read_tool_result 继续使用各自原有的许可策略；收紧 read_file 不会删除历史文本或改变历史工具的授权规则。

## 固定评测

用同一双包金额项目，正例按“目录 → 正文 → 报告格式 → 修改/测试/报告”完成；负例显式加载要求自动脚本的恶意技能，当前 read-only 策略必须拒绝一次 terminal 调用，实际启动/计数/输出均为零。冻结输入与版本见 `researches/skills/cases.mjs`；每例最多 8 请求、12 工具、120 秒、零重试，当前模型配置不变。离线与真实服务分别记录，不推断泛化成功率。
