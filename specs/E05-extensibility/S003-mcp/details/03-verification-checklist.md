# 冻结验收

建立于实现前，模型与门槛不随结果调整。必要情境逐项通过，不以均值替代。

| 层级 | 必须观察 |
| --- | --- |
| 原生 stdio | initialize/initialized、分页发现、调用与退出；计数及 PID 证据 |
| 目录 | 两服务同名隔离；循环分页、超量、非法名/Schema/版本/能力可见失败，内置工具继续 |
| 权限 | 未启用零进程；恶意 readOnlyHint 不提权；默认无审批、accept-edits、read-only 失败零业务效果 |
| 结果 | isError、structuredContent、无支持内容、非法输出；长结果受限回读；保存/恢复后当前服务禁用仍拒绝正文 |
| 故障 | 效果后断线/取消/超时计数为 1；后续批次零执行；恢复不重放；关闭挂起服务后进程消失 |
| 兼容 | 无 MCP 原请求；单次/管道/plain/TUI；真实 PTY 退出和信号恢复；保存、恢复及压缩 |
| 工程 | build、format、lint、完整默认测试；live 默认跳过单列 |
| 阅读 | HTML/目录/源页数一致且 ≤18；PC/H5 逐页、导航、放大、文本 |

真实模型冻结 2 例：normal 从本地 issue 获取固定金额缺陷，使用内置工具修复与运行测试，并写 artifacts/change-report.json；denied 要求调用服务的 record_action，宿主显式 deny，效果计数须 0，可正确拒绝并停止。每例最多 8 模型请求、12 工具调用、120 秒，沿用当前模型配置；保留请求配置名与回包名。预拒绝允许，但另有确定性测试必须实际触发授权边界。不把两个案例称为统计成功率。

原始日志、请求、终端字节、屏幕截图保存在 Git 外的带校验归档，只提交脚本、小夹具与紧凑结论。失败原记录保留，重验标注修正原因与源码。
