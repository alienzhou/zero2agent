# MCP 工具的生命周期与授权

## 冻结范围

协议固定 2025-11-25；采用官方 TypeScript SDK 的 Client 与消息校验，锁定兼容版本。stdio 传输添加字节、时间和进程清理上限。仅工具发现/调用、文本及 structuredContent；不实现远程 HTTP、OAuth、Resources/Prompts、Sampling、Elicitation、Tasks、多媒体。

配置读取没有启动效果。SDK 调用方用 enabled:true，CLI 用显式配置路径与 --mcp-enable ID 授权启动。命令必须绝对路径；argv 数组、无 shell，环境只传显式键值。启用本地进程不提供操作系统隔离。工具统一视为 execute，忽略自报只读/idempotent 提示；accept-edits 不自动准许，read-only 拒绝外部调用，default 走审批/显式规则。

每轮建立连接并分页发现，工具表在轮内固定；变化通知阻止旧表调用，下一次用户显式操作刷新。名称由服务 ID 与原名摘要稳定生成，不截断后碰撞。身份含命令、参数、cwd、显式环境的哈希；快照不存凭据、配置和进程。当前配置停用或身份变化，旧结果正文不能仅凭本地文件权限回读。

输入与可选输出采用 JSON Schema 2020-12，拒绝未知关键字/外部引用/不支持方言，编译失败不降级。已收到 isError 保留工具失败；传输、取消、超时或无法解释的回包发生于发出调用之后，记录 unknown，停止本轮，配对未开始项，保留已完成项。再次运行前要求显式恢复说明；业务调用永不自动重试。

## 固定容量

最多 4 个配置服务、每服务 32 个工具、8 页；单页/消息 1 MiB、单连接累计输入 16 MiB、输出请求 256 KiB、配置 32 KiB。启动/发现共享 10 秒；每次工具调用 30 秒（仍受原 turn 总预算约束）；关闭先 TERM 等 250ms 再 KILL 等 250ms。目录循环游标、容量超限、协议不兼容均关闭该服务并给可见状态，内置工具继续可用。测试使用较短的合法超时，不提高默认容量。
