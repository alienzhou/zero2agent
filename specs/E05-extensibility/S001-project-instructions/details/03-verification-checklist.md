# 逐项验收

所有条目必须通过；当前均待实现验收。证据将记录源版本、命令与结果；默认跳过的 live 测试单列，人工 review 不由 AI 代签。

| 场景 | 必须观察的结果 |
| --- | --- |
| 根、嵌套、兄弟、跨目录批次 | 实际请求来源/作用域正确，兄弟不误用，无重复无限注入 |
| 首次嵌套写入 | 首批效果为零，配对明确未执行，新请求先见规则 |
| 明确用户覆盖与恶意正文 | 用户覆盖语义在请求中明确；越界/拒绝的实际效果为零 |
| 无文件、拒绝、不可读、超限、符号链接 | 缺失不影响旧行为；错误可区分；无静默截断或受影响写入 |
| 更新、删除、压缩、恢复 | 使用当前版本；历史不改写；审批不继承 |
| 审批中修改、批中自改规则 | 副作用前重验；保留此前效果；后续不执行、不重放 |
| 查看/刷新/关闭 | CLI/plain/TUI 来源与请求一致，查看零模型请求，关闭兼容 |
| 取消/退出 | 实际 PTY 无输入所有权泄漏，清理完成后再接收输入 |
| 各容量与重规划 | 阈值前/等于/超过都有断言，次数有界 |
| 跟练与真实模型两例 | 文件字节、测试和报告可检查，失败附件保留 |
| 工程与课程 | build/type/lint/format/full regression；源/产物一致；PC/H5 可读 |
