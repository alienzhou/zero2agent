# E03-S003：范围与后续问题

[课程](../README.md) | [设计](./01-technical-design.md)

| 后续能力 | 去向与原因 |
|---|---|
| 会话列表、退出再恢复 | S004；本课仅维护进程内状态 |
| 永久结构化日志、跨进程回放 | S005；RuntimeEvent 是界面事件，未承诺日志兼容协议 |
| 文件撤销与 diff 回滚 | S006；取消保留已发生副作用 |
| Web UI、多客户端事件订阅 | 后续；先用一个真实终端验证控制契约 |
| 丰富 Markdown、鼠标选区、复杂布局与组件库迁移 | 使用反馈后评估；当前以输入/取消可靠性为先 |
| 所有系统的完整终端矩阵 | 各目标系统单独验收，不能从本机结果推断 |
| 强制终止任意自定义 JS 工具 | 需 Worker/进程隔离；当前协作 signal + 等待真实结束 |

## 被拒绝的方案

- 解析 stdout 推断状态：工具名、文本与执行身份会混淆。
- 将 onEvent 返回值作为权限响应：观察者错误会改变执行。
- 取消时 Promise.race 后直接开放输入：工具仍在后台写入，新 Turn 可能同时操作。
- 以停止 spinner 代表停止 Agent：没有控制模型、权限或工具生命周期。
