# 后续问题与不做清单

[课程](../README.md) | [设计](./01-technical-design.md)

| 题目 | 本版边界 | 延伸 |
| --- | --- | --- |
| 任意 shell 捕获 | 不猜路径，不扫描全目录，不声称可退外部副作用 | 未来需要沙箱/文件系统隔离或显式用户选择范围 |
| 整轮/多轮回退 | 每次工具调用一条记录，逐条撤销；没有时间线整轮 rewind | 聚合记录还要处理依赖与中途外部编辑 |
| 文本最小 diff / merge | 连续替换窗口，冲突即拒绝，没有强制覆盖 | [patch 与分块](../deep-dive/01-patches-and-chunks.md) |
| 多文件原子性 | 持久化意图与可继续状态，不是全局事务 | [恢复也是写入](../deep-dive/02-recovery-is-a-write.md) |
| 全文件系统元数据 | 只字节/rwx；不恢复 ACL、属主、xattr、目录时间和空目录清理 | 不伪装成系统备份工具 |
| 大文件/内存 | 每文件 32 MiB、单调用 64 MiB；全文件有界缓冲 | 流式哈希/分块可进一步降低峰值 |
| 极短锁初始化崩溃 | owner/claim 不完整时保守拒绝 | 可设计单独诊断维修命令，不能自动删未知锁 |
| 跨平台持久性 | 本机验证，未测网络卷和断电 | 按平台建立故障矩阵 |
| 长期数据管理 | 最近 50 条、30 天、字节预算，手动 prune | 不提供用户自定义 TTL/预算 CLI、归档、加密或远程同步 |
| Git pack / CDC 更多对比 | 当前合成高熵插入语料，简单存储基线 | 增加真实代码、大量小文件和不同改动分布；同等持久保证对比 |

明确拒绝：以隐藏 Git 代替本课存储；对整个仓库无条件复制；只保留无法验证的模型“成功”文字；容量失败时悄悄继续不受保护写入；缺 after 就自动重试工具。
