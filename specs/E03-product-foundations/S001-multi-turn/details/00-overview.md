# E03-S001：总览

[Story](../README.md) | [Epic 3](../../README.md)

## 迭代目标

把历史所有权从单轮局部变量提升到进程内 Session，并把“保留原始记录”与“发送工作上下文”分开。本期同时实现多轮会话、请求预算、多级自动后台／前台压缩与手动 `/compact`；压缩不再是本期排除项。

> 当前状态：生产代码 `ea498a3` 实现完成且未变，最终验收测试 `3829868` 全量 379 通过、25 跳过，功能分支已推送至 `50d1c1a`。18 页图文本地成稿与交付包验证完成、未发布，真实模型试用未执行。旧测试记录仅说明当时的多轮范围。

## 核心功能

- Agent 实例共享 Session；独立实例、静态调用与默认 runLoop 隔离。
- 原始历史保存完整回答、工具对与失败证据；getHistory / getContext 提供不同的深拷贝视图。
- 完整请求预算覆盖 system/tools/messages 与输出安全预留；未知模型显式窗口，provider 计数失败不放行。
- 先缩短大工具正文并保留临时文件引用，再以输入预算的 0.65 启动后台、0.85 转前台，向 0.45 目标缩减。
- 后台只总结稳定前缀，采用时保留增量；取消与 reset 让过期任务失效。摘要自身分块计数、有限重试，失败不丢原史。
- 手动 `/compact` 前台执行，与同 Session 的 run/reset 互斥；主模型上下文拒绝最多恢复两次，不重放已执行工具。
- `/new` 清空历史与摘要，保留配置及工作目录，不回退文件或停止命令。

## 课程顺序

先从“接着上一轮改”与“大工具结果放不下”两个场景出发，理解 Session / Turn / Loop 和两种历史视图；再讲预算、自动层级与后台并发，最后通过[分步跟练](../follow-along.md)验证手动入口。先用 mock 和本地服务验证契约，真实模型体验需单独确认费用与数据边界。
