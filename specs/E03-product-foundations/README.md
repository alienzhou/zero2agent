## 课程边界

- **会话与基础压缩一起讲。** S001 维护进程内原始历史，在完整请求预算下组织工作上下文；先缩短大工具正文，再后台摘要，接近上限时前台等候／压缩，并提供手动 `/compact`。保留消息配对、失败证据、稳定前缀与增量，压缩不改原史、不回滚文件。落盘恢复仍放在 S004。
- **Approval 靠前讲。** S002 先用简单终端提示跑通授权，S003 再接入 TUI。复用并梳理已有工作目录校验，不能把路径校验或用户批准当作 shell 沙箱；E02-S004 的人工终端确认也不等于通用权限机制。
- **架构随交互需求改造。** 基于已有 Core 事件回调补齐状态与控制接口，不单开抽象重构课，也不在本阶段实现 Web UI。
- **恢复与回退各有边界。** S004 不恢复旧进程；S005 不把所有日志灌进模型上下文，也不改变人工终端正文不采集的约定；S006 的回退范围是文件，不是外部系统状态。

高级摘要质量评估、更复杂的上下文工程与复杂异常恢复留给 Epic 4；基础预算和分级压缩已移入本期，不再作为 Epic 4 的独占范围。AGENTS、Skills、MCP、Hooks 留给 Epic 5。
