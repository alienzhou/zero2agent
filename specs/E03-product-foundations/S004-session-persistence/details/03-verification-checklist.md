# 验收清单

- [ ] 进程 A 保存，进程 B 恢复后真实请求包含旧上下文
- [ ] 恢复不执行旧工具、不恢复进程/审批/凭据
- [ ] 原始消息与已采用摘要可恢复；临时正文替换不持久化
- [ ] 未知版本、损坏内容、断裂配对、错误目录、并发写入均明确失败
- [ ] pending 运行仍活跃时不恢复；崩溃后恢复结算边界并提醒检查文件
- [ ] 保存失败不丢内存；切换失败保留当前会话；--no-save 不落盘
- [ ] TUI 选择器有独占焦点，取消保留草稿；旧交互全回归
- [ ] PC/H5 逐页布局、导航、图解放大和正文可读

验证结果与人工审查状态在交付前据实填写。
