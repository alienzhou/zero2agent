# 验收检查清单

以下状态在实际执行后更新，不把未运行项记为通过。

- [ ] 正常请求、工具调用、审批、失败、取消与下一轮可按 ID 关联。
- [ ] 主请求、摘要与 provider 计数有起止状态；SDK 内部重试边界说明准确。
- [ ] 新建/恢复/保存失败与人工终端生命周期可追查；正文不采集。
- [ ] 默认日志、关闭日志、多进程独占与工作区隔离。
- [ ] 含密钥/正文的输入、响应和异常不出现在日志；observer 错误不影响执行。
- [ ] 队列/文件上限、写入/打开失败可见，任务继续，日志不会冒充完整。
- [ ] 正常退出刷新；强制终止可读取完整前缀并报告未闭环。
- [ ] UUID、软链接、版本、中部损坏、残缺尾行与显示数量限制。
- [ ] 无 API key 的列表/查看不调用模型；日志读取不修改会话或工具文件。
- [ ] TUI 草稿/粘贴/快捷键、审批、取消、压缩、会话、PTY 与 plain/管道回归。
- [ ] 构建、类型、lint、格式、离线测试、真实模型与原始失败证据。
- [ ] 20 页渲染无越界，PC/H5 导航、文字、放大与系列封面。
- [ ] 来源固定版本、文档互链、生产/测试/教材哈希和最终交付审计。
