# 边界与延伸

| 本课不做 | 理由 / 后续方向 |
| --- | --- |
| payload 正文记录 | 默认元信息白名单；含文件、prompt 的导出需要独立隐私设计 |
| 云遥测、OpenTelemetry exporter | 先跑通本地追查；延伸文对照 span 与日志 |
| 自动日志清理、压缩归档 | 单文件有上限，总磁盘占用仍需后续保留策略；列表遍历目录后排序，500 是展示上限，不是全目录扫描预算 |
| 文件回滚、工具重放 | E03-S006 checkpoint 范围，不能从缺失日志推断副作用 |
| 每个 SDK 内部 HTTP retry | 目前记录逻辑 SDK 调用，不伪造网络层证据 |
| 网络卷、Windows、断电强持久性 | 仅按实际平台验证；fsync 不等于完整事务 |

话题池：01「日志缺了一行，为什么不能重试工具？」；02「从本地 ID 到分布式 trace」。完整延伸文：[副作用边界](../deep-dive/01-logs-and-side-effects.md)、[日志与 Trace](../deep-dive/02-log-and-trace.md)，已随本课提供。
