# E03-S005 迭代概述

[课程主线](../README.md) | [Epic 3](../../README.md)

目标：出问题时可以串联一次宿主运行、会话、操作、模型请求、权限和工具结果。日志在程序关闭后仍可读，读取不需要 API key，不调用模型或工具。

交付：Core 元信息诊断事件；宿主 JSONL 日志、有界写入与可见失败；CLI / TUI 浏览；请求/工具耗时、用量、错误分类；完整教学、研究与分层验收。

边界：日志默认不保存对话、参数、工具正文与私密终端字节；不回滚文件、不自动导入上下文、不连接云端遥测。本课使用本地文件系统，不声称断电持久性或跨主机跟踪。
