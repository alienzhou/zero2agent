# E02-S002: 验收检查清单

> 开发过程中需要特别关注的检查项。

---

## 功能验收

### replace_in_file 基础功能

| 检查项 | 优先级 | 模块 |
|--------|--------|------|
| 唯一匹配时替换成功，且只动那一处 | P0 | Tools |
| 替换后保留文件其余内容不变 | P0 | Tools |
| `old_string` 精确匹配（含空白/缩进） | P0 | Tools |
| `new_string` 为空字符串时等价删除片段 | P0 | Tools |
| `replace_all: true` 替换所有匹配处 | P0 | Tools |
| `replace_all: true` 回执报告实际替换处数 | P0 | Tools |
| 工具正确注册到 allTools | P0 | Tools |
| Agent 循环能正确调用 replace_in_file | P0 | Loop |

### 匹配语义验收

| 检查项 | 优先级 | 说明 |
|--------|--------|------|
| 0 次匹配 → `Match not found` | P0 | 不静默跳过 |
| ≥2 次匹配（默认）→ `Match not unique` | P0 | 不自动选第一个 |
| 多匹配时回执提示补充上下文 | P1 | 引导模型带上更多上下文 |
| `replace_all: true` 且 0 次匹配仍报错 | P1 | 全量替换也不静默跳过 |

## 安全边界验收（本 Story 重点）

| 检查项 | 优先级 | 说明 |
|--------|--------|------|
| 改 `../` 之外路径被拒绝 | **P0** | 返回 `Error: ... outside the workspace` |
| 改绝对路径逃逸被拒绝 | **P0** | 如 `/etc/hosts` |
| 目标是目录 → 拒绝 | **P0** | 返回 `Error: ... is a directory` |
| 文件不存在 → `File not found` | **P0** | 与 read_file 措辞一致 |
| 越界拒绝时不产生任何磁盘副作用 | **P0** | 拒绝即中止，不读不写 |

---

## 回执契约验收

| 检查项 | 优先级 | 说明 |
|--------|--------|------|
| 成功回执为可读字符串，报告替换处数 | P0 | 沿用 `Promise<string>` |
| 错误回执以 `Error:` 前缀 | P0 | 与既有工具一致 |
| 回执为英文措辞，与既有 6 个工具一致 | P0 | 吸取 S001 doc/code 漂移教训 |
| 不引入结构化返回类型 | P1 | 维持 string 契约 |

---

## 边界场景

### 输入边界

| 检查项 | 优先级 | 说明 |
|--------|--------|------|
| `old_string` 为空字符串 → 拒绝 | P0 | 返回 `Error: old_string must not be empty` |
| `new_string` 为空字符串 → 删除片段 | P0 | 等价局部删除 |
| `old_string` 含 `$` 等特殊字符 | P1 | 按字面量匹配（split/join 规避占位符） |
| `new_string` 含 `$` 等特殊字符 | P1 | 按字面量写入，不被解释为替换占位符 |
| `replace_all` 缺省视为 false | P1 | 默认唯一匹配 |

### 状态边界

| 检查项 | 优先级 | 说明 |
|--------|--------|------|
| ToolContext.cwd 正确注入 | P0 | 基于 ctx.cwd 解析 |
| 替换过程原子性（先读后写） | P1 | 读失败不写；写失败返回 Error |

## 回归验收

| 检查项 | 优先级 | 说明 |
|--------|--------|------|
| 现有 6 个工具行为不变 | P0 | 本 Story 不改它们 |
| ToolContext 接口未改动 | P0 | 维持只有 cwd |
| `resolveInsideCwd` 行为不变 | P0 | 复用不修改 |
| TypeScript 编译通过 | P0 | 全仓库 |

---

## 已知限制

| 限制 | 说明 |
|------|------|
| 无破坏性确认 | 局部替换不弹确认，留后续专章 |
| 无软链解析 | cwd 内软链指向外部不在防护范围 |
| 无「先读后写」约束 | 替换前不强制先 Read |
| 无多文件/多段替换 | 一次调用只改一处（或 replace_all） |
| 无 instruction 语义编辑 | 只做确定性字符串替换 |
| 无回滚 | 替换不可撤销，Checkpoint 留 Epic 3 |

---

## 优先级定义

- **P0** = 必须通过，不通过则不可发布（安全边界项全部 P0）
- **P1** = 应该检查，影响用户体验
- **P2** = 建议检查，边缘场景，可后续完善
