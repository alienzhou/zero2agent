# E02-S001: 验收检查清单

> 开发过程中需要特别关注的检查项。

---

## 功能验收

### write_file 基础功能

| 检查项 | 优先级 | 模块 |
|--------|--------|------|
| 文件不存在时创建成功 | P0 | Tools |
| 文件已存在时覆盖成功 | P0 | Tools |
| 父目录不存在时自动创建（mkdir -p） | P0 | Tools |
| 回执区分「已创建」vs「已覆盖」 | P0 | Tools |
| 回执包含写入字节数 | P1 | Tools |
| 全量写入（content 即完整内容，不 append） | P0 | Tools |
| 工具正确注册到 allTools | P0 | Tools |
| Agent 循环能正确调用 write_file | P0 | Loop |

### delete 基础功能

| 检查项 | 优先级 | 模块 |
|--------|--------|------|
| 删除单个存在的文件成功 | P0 | Tools |
| 删除多个文件（数组）成功 | P0 | Tools |
| 部分失败时不中断，其余继续删 | P0 | Tools |
| 删不存在的文件 → 该项标记为失败（文件不存在） | P0 | Tools |
| 删目录 → 该项标记为失败（不支持删目录） | P0 | Tools |
| 回执逐条汇总成功与失败 | P0 | Tools |
| 全部失败时用 `Error:` 前缀 | P1 | Tools |
| 工具正确注册到 allTools | P0 | Tools |

## 安全边界验收（本 Story 重点）

| 检查项 | 优先级 | 说明 |
|--------|--------|------|
| write_file 写 `../` 之外路径被拒绝 | **P0** | 返回 `Error: 超出工作区` |
| write_file 写绝对路径逃逸被拒绝 | **P0** | 如 `/etc/hosts` |
| delete 数组中每个路径都单独过边界校验 | **P0** | 不能因在数组里就跳过检查 |
| delete `../` 逃逸项被标记为失败（越界） | **P0** | 不删，逐条汇总里体现 |
| 越界拒绝时不产生任何磁盘副作用 | **P0** | 拒绝即中止，不写不删 |

---

## 回执契约验收

| 检查项 | 优先级 | 说明 |
|--------|--------|------|
| 成功回执为可读字符串 | P0 | 沿用 `Promise<string>` |
| 错误回执以 `Error:` 前缀 | P0 | 与 Epic 1 工具一致 |
| 错误文本区分常见错因 | P1 | 文件不存在 / 是目录 / 超出工作区 / 权限不足 |
| 不引入结构化返回类型 | P1 | 维持 string 契约 |

---

## 边界场景

### 输入边界

| 检查项 | 优先级 | 说明 |
|--------|--------|------|
| write_file content 为空字符串 | P1 | 应能写出空文件 |
| delete paths 为空数组 | P1 | 返回「无文件可删除」类提示，不报错 |
| write_file path 指向已存在目录 | P0 | 返回 `Error: 是目录` |
| delete 同一路径重复出现 | P2 | 首次删成功，后续标记为「文件不存在」 |

### 状态边界

| 检查项 | 优先级 | 说明 |
|--------|--------|------|
| 权限不足（EACCES）| P1 | 返回可读的权限错误 |
| ToolContext.cwd 正确注入 | P0 | 两个工具都基于 ctx.cwd 解析 |

---

## 回归验收

| 检查项 | 优先级 | 说明 |
|--------|--------|------|
| 现有 4 个只读工具行为不变 | P0 | 本 Story 不改它们 |
| ToolContext 接口未改动 | P0 | 维持只有 cwd |
| TypeScript 编译通过 | P0 | 全仓库 |

---

## 已知限制

| 限制 | 说明 |
|------|------|
| 无破坏性确认 | 覆盖、删除都不弹确认，留后续专章 |
| 无软链解析 | cwd 内软链指向外部不在防护范围 |
| 无递归删目录 | delete 只删文件 |
| 无 append / 局部改 | 留给 S002 replace_in_file |
| 无「先读后写」约束 | 覆盖前不强制先 Read |
| 无回滚 | 删除、覆盖不可撤销，Checkpoint 留 Epic 3 |

---

## 优先级定义

- **P0** = 必须通过，不通过则不可发布（安全边界项全部 P0）
- **P1** = 应该检查，影响用户体验
- **P2** = 建议检查，边缘场景，可后续完善
