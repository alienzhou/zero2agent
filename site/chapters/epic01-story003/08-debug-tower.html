Agent Debug 方法论
Vibe Coding 最怕修不好的 Bug
1
纯静态分析 入门起点
Agent 通过看代码、看报错，梳理链路来“脑内”Debug
天花板低但门槛也低
2
预埋日志 基础保障
在开发阶段就在关键链路里写日志
运行时出问题可以让 Agent Grep 日志来分析
3
动态日志 高“性价比”
在开发阶段，让 Agent 分析问题后动态补充日志埋点
复现后针对性分析日志，再讨论改法
4
CDP 简单调试 MVP
打断点、暂停、读变量、拉调用栈
可以像人一样进行简单的 Debugger 操作，及时性不错
5
CDP 高级能力 能力最强
条件断点、Heap 分析、性能 Profile
理论上可以达到高级工程师的“调试能力”
1/2层几乎每个项目都可以做，养成让 Agent 加日志、出问题让 Agent 看日志的习惯，对于调用链路较长的问题，Debug 效果有明显提升。
