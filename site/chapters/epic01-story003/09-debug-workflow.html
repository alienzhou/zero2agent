Agent Debug 方法论
假设验证 + 动态日志，是非常有效的 Agent Debug 方案，工作原理如下：
1
用户：描述问题
2
Agent：基于问题，分析代码，生成 3-5 个假设
3
Agent：在代码中插入日志埋点，贯穿各个假设链路
4
用户：复现问题（或 Agent 自己 E2E）
5
Agent：读取刚才埋的日志信息，分析每个假设
6
Agent：基于确认的假设进行修复
// 日志分析结果示例
H1: 状态同步问题 （日志显示状态一致）
H2: API 超时 （日志显示请求耗时 5200ms）
H3: 边界条件 （未触发该路径）
日志为 Agent 提供了关键的运行时信息
