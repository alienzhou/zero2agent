为什么只有 read_file
是不够的？
旧工作流 盲读与猜盲盒
猜文件路径 → read_file → 没找到 → 继续猜下一个
在第一课中，我们给了 Agent 查看文件的能力。但这导致了极其低效的行为：当遇到大项目时，它要么把整个文件从头读到尾吞噬 Token，要么靠瞎猜路径疯狂试错。
新工作流 搜索驱动
grep_search 模糊定位 → 选择候选文件 → read_file 精读
真实的工程师从不会通读整个项目，而是先搜索关键词，再打开相关文件精读。这一课的核心，就是让 Agent 获得这种“先定位、再精读”的基础工作流升级。
