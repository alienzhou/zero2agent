Zero2Agent · 行业分析 07
各大 Coding Agent，
都在用什么搜索方案？
目前（2026.03），绝大多数的 Coding Agent 产品，在核心链路上都拒绝了 RAG（语义搜索），而是坚守了 Grep。
Product Grep Search RAG Codebase Notes
Claude Code ■ — 明确不做 embedding，通过拉起子 Agent 执行多步搜索
Cursor ■ ■ 自研模型，基于本地 mmap 构建极致性能的 regex index
Codex CLI ■ — 围绕 rg 构建结构化工具能力，暂无原生语义支持
Gemini CLI ■ — 官方推荐复杂的语义搜索需求交由外部 MCP 解决
Aider ■ — 使用 tree-sitter 构建 repo map 提供全局视野，不搞向量化
Windsurf ■ ■ 引入专职搜代码的小模型 (SWE-grep) 配合语义索引使用
OpenCode ■ — 主要依赖封装 ripgrep，尝试补充 LSP 结构能力
■ 代表作为主要内置方案支持    — 代表明确未内置或放弃
