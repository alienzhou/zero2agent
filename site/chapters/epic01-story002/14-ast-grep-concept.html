AST + Grep：
把代码作为语法树检索
前两者的还是在解决纯文本搜索的局限。而 ast-grep（13k+ Stars）代表的是一条全新的维度：不搜文本，改搜结构。
文本正则的脏数据原罪
如果你的 Agent 想在一大推代码里找 fetchUserData，传统的 grep 会把注释里、长篇 Markdown 文档里、甚至报错字符串常量里的同名字符全部兜回来。Agent 花了海量 Token 读了一堆毫无执行价值的垃圾。
Tree-Sitter
ast-grep 借用了 tree-sitter 这个很好用的库，在搜索发生前，就已经把源码解析为抽象语法树 (AST)。你用的不再是反人类的 Regex 猜边界，而是直接写一段带占位符的合法代码模式。
// 查找并匹配任意变量的 console 调用
sg -p "console.log($ARG)"
