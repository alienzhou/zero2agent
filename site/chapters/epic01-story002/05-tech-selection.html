Zero2Agent • 技术选型 05
Grep 基础能力怎么选？
技术选型：
在决定给 Agent 做 Grep Search 工具时，我们可以在「工具能力」「性能表现」「生态情况」「鲁棒性」「跨平台兼容性」上做出权衡。
方案1: 系统内置
(grep / rg)
✓ 引入依赖最少，接入成本极低
✗ 跨平台兼容性最弱，重度依赖宿主机预装环境
✗ 版本差异极大，不利于可能的精细控制
方案2: 自己手写
(fs + RegExp)
✓ 绝对可控，无第三方依赖顾虑
✗ 很容易实现不好性能差，在大仓库中急剧退化
✗ 需要覆盖的功能多，里文件过滤、.gitignore 解析
方案3: 成熟组件
(基于 ripgrep)
✓ 性能好，天然支持工程级排障（如识别 gitignore）
✓ 生态成熟，大模型很懂它，Agent 更容易写对参数
✓ 有成熟的跨平台兼容方案
竞品情况：拆解调研 OpenCode、Pi、Gemini CLI 等产品，大部分选择了基于 ripgrep 构建能力。不过在“如何为 Agent 封装参数并截断排序”互有差异。
