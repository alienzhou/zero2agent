新增一行，也能用替换表达

先找到唯一锚点，再把锚点和新增内容一起写回

插入：保留原文，附上新行

old_string · 精确匹配这行

const retries = 3;

new_string · 原文 + 新增内容

const retries = 3;
const cache = true;

原来的重试配置保留下来，缓存配置插在它后面。

删除：把目标片段换成空字符串

old_string: "const retries = 3;\n"
new_string: ""

把换行也纳入原文，删除整行时就不会留下空行。

每个例子独立执行。old_string 不能为空：空原文没有明确的定位锚点，本版直接拒绝。
