Zero2Agent · 按键试验08

按 Ctrl-C，
为什么不一定回到 Agent？

先区分：操作当前程序，还是中止整场接管

本机 Node 转录 · 方括号是动作说明

> n *  [不回车，按 Ctrl-C]
>      [清空本行，仍在 Node]

同样输入 .exit，返回位置不同

第 2 页 · 直接启动 Node

Node ─ .exit → Agent 对话

第 12 页 · 先进入 bash

Node ─ .exit → bash ─ exit → 原命令行

less 的 q 也是退出当前程序，不会顺带退出外层 bash。

Ctrl-]

要中止整场接管，用这个键

宿主拦截并清理受管进程；不是把程序切到后台继续跑。

Ctrl-C / D 交给程序与终端模式解释。Ctrl-D 在按行输入的空行上通常表示 EOF，不是通用退出键。
