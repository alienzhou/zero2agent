怎么知道接好了？
别只试一句 Hello

用三个现象，检查交互链是否完整

01

定义 n = 21，再算 n * 2

预期：第二次输入得到 42。

若 n 丢了 → 先查是否每次都重启进程。

02

打开 less，再缩小窗口

预期：按新尺寸分页、重绘。

若画面不变 → 先查 resize 是否传到 PTY。

03

从 /terminal 返回，再输入

预期：输入回到 Agent，不残留在程序里。

若回显错乱 → 先查终端模式与监听恢复。

以上是排查起点，不是唯一归因。本机 macOS 已有真实 PTY 验证，用户两项功能试用反馈正常。

Linux 未实测 · Windows 不支持
