Zero2Agent · 实现骨架06

接通输入和输出，
代码里是哪两条线？

只看桥接骨架，就能理解数据怎么走

① 输入桥 · 你敲的 n * 2 从这里经过

input.on('data', bytes => {
  pty.write(decode(bytes))
})

少了这一条，程序可以显示提示，却收不到你的按键。

② 输出桥 · Node 算出的 42 从这里回来

pty.onData(text => {
  output.write(text)
})

少了这一条，程序即使执行了，你也看不到返回结果。

连接伪代码：decode 表示 UTF-8 流式解码。省略输入独占、窗口同步、背压和退出清理，不是完整实现。

--terminal 独立启动 · /terminal 对话内启动
模型用 interactive: true 请求，三者共用桥接。
