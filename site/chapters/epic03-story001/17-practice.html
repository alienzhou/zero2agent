跟练：追问、压缩、再清空

含压缩的候选确认后，在项目根目录启动

Node.js 22+ · pnpm 9+ · 先配置模型与 API

pnpm install
pnpm build
node packages/tui/dist/cli.js

未知模型要配 CONTEXT_WINDOW；可设 MAX_INPUT_TOKENS、MAX_OUTPUT_TOKENS 与 CONTEXT_COUNTING。

1

先形成可追问的历史

说「代号 cedar-17，先分析测试结构，不改文件」，等完成后追问建议。

2

输入 /compact，再追问代号

观察压缩状态；短历史未必能缩小，不要编造成功结果。

3

/new 后再问是否知道代号

旧上下文不应再发送。逐条等「你:」再输入，最后 exit。

自然语言与摘要会调用 API。压缩实现与自动验证已合入 main 并打 Tag；课程尚未对外发布。
