把 Session 留在 Agent 里

复用同一个实例，让历史跨过函数返回

agent.ts · 节选，省略模型与工具配置

class Agent {
  private session = new Session()
  async run(message: string) {
    return runLoop(message, {
      session: this.session
    })
  }
}
const agent = new Agent()
await agent.run('先分析测试')
await agent.run('按刚才的建议改')

同一实例

两次 run，共用一段历史。

新建实例

独立会话，不会串入旧消息。

静态 Agent.run() 每次都是一次性调用。直接用 runLoop() 时，需显式传入同一个 Session 才会延续。
