Zero2Agent · 手动前台压缩13

想现在整理，就输入 /compact

一段工作告一段落，可以主动收紧工作上下文

/compact

宿主识别命令
前台等待压缩完成

不会做什么

不把命令当普通问题，不新增用户轮次，不重跑历史工具。

可能做什么

等待已有后台任务，再调用模型摘要；会产生 API 用量。

SDK · 同一个 Agent 实例

const changed = await agent.compact()
const context = agent.getContext()
const history = agent.getHistory()

changed 表示是否采用了压缩结果。getContext() 是消息视图，不含独立的 system/tools；getHistory() 是完整记录的深拷贝。
