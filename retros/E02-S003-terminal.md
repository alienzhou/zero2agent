# E02-S003-terminal Retrospective

> 迭代：E02-S003（驱动执行环境）· 日期：2026-09 · 关联：[Story README](../specs/E02-act-and-execute/S003-terminal/README.md) · [讨论记录](../.discuss/2026-08-26/e02-s003-terminal/outline.md)

## Summary

给 Agent Harness 装上执行工具 `terminal`，让它第一次能跑一条我们没写的程序，并拿到 stdout / stderr / exit code。核心产出不是 spawn 本身，而是五套机制：回执契约、超长输出落盘、取消/跳过、进程三道防线、执行环境采集与覆盖。

这是 Agent 从「盲写」到「能验证自己的工作」的一步，也是课程里第一次把控制权交给外部进程。S004 只剩「要不要人输入」（`stdin` / pty）。

## What Went Well

- **调研是实证，不是推断**：五家竞品每条结论带 `文件:行号`，直接回应了 S002 复盘「调研偏推断」的教训。后面推翻竞品共识时，才站得住。
- **五个议题按耦合度推进，而不是按工作量切章**：长命令和进程生命周期最初划给 S004，讨论里判定「这是 S003 自己制造的问题，不能留给下一章」，线被重画了两次。判据本身后来成了教学内容。
- **有意偏离写清了前提**：不截断、不默认杀死、不抄 Gemini 的 `TERM=xterm-256color`。三条都是「抄值不抄前提就会抄错」的实例，T01–T14 里被推翻的早期建议原样留着当轨迹。
- **零新工具解决超长输出**：落盘后用已有的 `read_file` / `grep_search` 回读。这是 E01「读工具做通用」的复利，也把「上下文预算」和「输出长度」拆开了。
- **验收按「会不会挂死」来写**：P0 evidence 和 D01–D05 live E2E（含 PTY 真按键）进了仓库，不只是单测绿。nonce 越狱、drain 超时、watcher 重定向这些项，不跑真进程验不出来。
- **回执从一开始就是英文**：S001 的 doc/code 漂移、S002 的 D06 约定，这次没有再犯。

## What Could Be Improved

- **实现合入后账本没跟上**：PR #11 已经把代码、spec、讨论都落进 `main`，但任务清单仍写「待开始」，Epic 页停在「Spec 已定稿」，CHANGELOG / 复盘 / Tag 都缺。读者从导航看，会以为这一章还没做。代码合并 ≠ Story 收口。
- **总览一度把 S003 写成 Epic 2 收官**：边界重画之后 S004 还在，定位句没有同步。Story 边界一变，入口页的「这一章在整段里的位置」要一起改。
- **协作记录仍缺 E02**：`.vibecoding/` 下没有 E02-S003。S001 复盘就记过这件事，两个写/执行迭代都没补上。
- **审查修了两处 P0 才稳定**：隔离标签闭合串带了不该有的属性、跳过后重复 detach。这两处都是「结构一旦写错，语义就反」的契约面，单靠实现当时的绿测不够，要靠对抗用例钉住。

## Lessons Learned

1. **划 Story 的判据是耦合度，不是工作量**：一个自己制造的问题（跳过留下活进程）不能推给下一章，否则下一章只能在别人的前提上打补丁。
2. **竞品做法要连着前提一起抄**：有人在环才能「无超时」；走 pty 才需要 `TERM=xterm-256color`。前提不成立，共识就是错的。
3. **回执里凡是结构，命令输出都能伪造**：固定名的隔离标签等于没有。nonce 必须每次随机，闭合标签不能带可被回声复刻的固定属性。
4. **进程杀了 ≠ 管道关了**：`setsid` 曾孙攥着继承来的 fd，`close` 不触发，Promise 永不 resolve。读取侧超时是在守「单一出口」，不是性能优化。
5. **防御措施自己会变成故障源**：为收孤儿加的 watcher，第一版不重定向 stdout，就会把自己挂死。新加的防护要按「它会不会制造新的挂死」再验一遍。

## AI Coding Notes

- **契约面（标签、detach 次数、回执字段）要写成对抗测试，不要只写 happy path**：模型实现时容易交出「看起来合法」的 XML / 生命周期，审查才能发现闭合标签不合法、跳过路径 detach 两次。
- **`detached: true` 之后不要 `unref()`**：文档和任务清单里已经写了，实现时仍可能习惯性加上，Node 会提前退出。
- **跨 chunk 必须 `Buffer.concat` 再 decode**：逐 chunk `toString('utf-8')` 会把中文 / emoji 切成 `�`，这条用一条跨 chunk 用例就能钉死。
- **状态文档和代码是同一次交付**：只合实现、不改 Epic / CHANGELOG / 任务清单，教学项目的读者路径会断。下次 Story 收口应和实现提交排在同一条完成定义里。
