# E05-S002：按需加载要覆盖整条执行链

Skills 的核心不是读一个 SKILL.md，而是让目录、正文、资源在正确时刻进入真实请求。首个请求只给摘要，模型选择后才加正文，需要报告结构时才读取引用；工具回执只保留加载元信息，避免把正文永久复制进历史。

标准核对固定到官方源码：YAML 头部和字段约束采用开放格式，默认发现目录、容量、审批和刷新属于本产品策略。allowed-tools 为实验声明，不是宿主许可；compatibility 是说明文本，不是依赖安装器。仓库原 CDP 示例缺少合规头部和匹配目录，随实现修正。

整批 load_skill 与写操作必须先停下来。即使宿主已读取正文，提出写操作的那次模型请求还没见过它，不能先写后补规则。单独加载后再请求，当前技能版本变化时有界重新规划；审批或批中变化保留前面的真实效果并停止剩余调用。新增资源工具沿用原预算、权限和结果来源协议。

完整回归发现普通会话复用会多出空 Skills 覆盖层，使既有请求发生变化。独立审阅又复现审批时文件头部被换大，以及恢复时当前 --skill 选择被旧快照抹掉。这些都是实际兼容/边界问题，需要修实现并补回归，不能只修改旧测试期待。原失败日志与复现目录保留到外部归档。

课程按必要教学步骤安排 11 页（含封面），展示层次、选择、批次时序、路径边界、脚本授权与恢复。完整容量和故障表放进 Spec。浏览器自动几何检查之后仍检查实际图像：初版 YAML 结束线贴底、资源边界箭头穿字，修正后重新验 PC/H5。所有截图、请求、PTY 和源副本留在忽略目录与独立归档，Git 仅放复现脚本和精简索引。
